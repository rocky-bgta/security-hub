ASAT Outlook Add-in Support

This page helps end users and administrators troubleshoot installation and reporting issues quickly for the ASAT Phishing Reporter add-in.

Last updated: May 2026

Quick Health Check

  1. Confirm you are signed in to the intended Microsoft 365 account.
  2. Update Outlook to the latest available version.
  3. Verify internet connectivity and any VPN/proxy restrictions.
  4. Restart Outlook and reopen the message, then try again.
  5. Check whether your administrator has deployed and allowed the add-in.

Install or Reinstall Guide

Outlook Desktop (Windows/Mac)

  • Go to Home → Get Add-ins.
  • Search for ASAT Phishing Reporter.
  • Select Add, then restart Outlook.
  • Open an email and use the Report A Phishing button.

Outlook on the Web / New Outlook

  • Open Settings → Manage add-ins.
  • Find and enable ASAT Phishing Reporter.
  • Reload the browser/app if the add-in does not appear immediately.

Common Issues and Fixes

Add-in is not visible
  • Ensure your IT admin deployed the add-in to your account or group.
  • Check Outlook client compatibility and mailbox type.
  • Sign out/in and restart Outlook.
Add-in stuck on loading spinner
  • Clear Office cache and restart Outlook.
  • Disable conflicting VPN/proxy or allow ASAT domains.
  • Retry with a stable internet connection.
Sign-in or session expiration loop
  • Check system time and timezone are correct.
  • Sign out from Office and sign in again.
  • Ask IT to review Conditional Access or SSO policy restrictions.
Reporting action fails
  • Retry from another message to isolate message-specific issues.
  • Capture the error text and timestamp, then contact support.

Administrator Troubleshooting

  • Confirm centralized deployment assignment in Microsoft 365 Admin Center.
  • Validate users have appropriate Outlook license and mailbox type.
  • Allow required ASAT endpoints in firewall/proxy/content filters.
  • Review Conditional Access rules that can block Office add-ins.
  • Check service health if users report broad outage patterns.

Collect Diagnostics Before Contacting Support

  • User email and organization/tenant name
  • Outlook client (Windows/Mac/Web/New Outlook) and version
  • Add-in version and exact error message
  • Date/time of issue and timezone
  • Screenshot or screen recording (if possible)

Tip: include correlation/request ID when available to speed up investigation.

Service Status and Security Notes
